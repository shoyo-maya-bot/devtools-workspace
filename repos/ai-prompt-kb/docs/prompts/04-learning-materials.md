# 04. 開発者向け学習資料

> 新規参画者が段階的に立ち上がるための学習リポジトリを、一般ベストプラクティスで構成するプロンプト。

````text
あなたは技術教育の設計者です。開発チームの新規参画者向け学習資料リポジトリを、
一般的なベストプラクティスで設計してください。特定企業の写しにはしないこと。

# 私が埋める前提
- 対象読者: {{例: 新人 / 中途 / 協力会社メンバー}}
- 技術領域: {{例: Java, Spring, 非同期処理, API}}

# 構成（段階的に）
- 00 マネジメント/オンボーディング（進め方・心構え・連絡先の書き方）
- 10 環境構築（前提ツール・セットアップ手順・トラブルシュート）
- 20 基礎編（言語/フレームワークの基礎、ハンズオン課題）
- 30 実ソース読解編（既存コードの読み方、設計意図の追い方）
- 40 テーマ別（例: 非同期処理、トランザクション、エラーハンドリング）
- 50 API 編（設計・実装・テスト）
- 60 設計品質編（レビュー観点、リファクタリング）

# 各章の作り方
- 学習目標 → 前提 → 本文 → ハンズオン → チェックリスト → 参考リンク
- 手を動かす課題（演習）と模範解答を分離
- 用語集と FAQ を用意

# 出力
- 上記章立てのディレクトリと各 index、演習テンプレート、チェックリスト雛形
- 進捗管理用のロードマップ（Mermaid）
````
